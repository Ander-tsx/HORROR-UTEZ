# Assets/_Project

Todo el contenido propio del juego. Terceros van en `Assets/ThirdParty/`.

| Carpeta | Contenido |
|---|---|
| `Art/Environment` | Modelos/materiales de entorno (edificios, terreno, vegetación) |
| `Art/Props` | Objetos sueltos |
| `Prefabs` | Prefabs de juego |
| `Scenes` | Escenas. Principal: `utez.unity` (campus). |
| `Scripts/Core` | Utilidades compartidas — `HorrorUtez.Core` |
| `Scripts/Player` | Movimiento y cámara del jugador — `HorrorUtez.Player` |
| `Scripts/World` | Generación de terreno y mundo — `HorrorUtez.World` (+ `World/Editor`) |
| `Settings` | URP Pipeline Assets, Volume Profiles, Input Actions |

Convenciones y fase actual: ver `/CLAUDE.md` y `/docs`.
